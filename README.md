# パンツァー語翻訳機

日本語または英語を入力すると、パンツァー語に翻訳して声に出すブラウザアプリです。
辞書と翻訳ルールは、パンツァー語の資料（パンツァー語辞典_ORTA.xls / パンツァー語辞書.xlsx / 翻訳手順）をもとにしています。元資料はリポジトリに含めず、辞書部分だけを `tools/source_dictionary.tsv` に取り出しています。

## 使い方

1. `index.html` をブラウザ（Chrome / Edge / Safari 推奨）で開く
2. 日本語か英語を入力して「翻訳して発声」を押す（`Ctrl + Enter` でも可）
3. 結果の単語をクリックすると、その単語だけを発声する

画面右上のボタンで、表示を日本語 / English に切り替えられます（初期値はブラウザの言語）。

### Web 公開（GitHub Pages）

`.github/workflows/pages.yml` で、`main` ブランチへの push ごとにテストを実行してから GitHub Pages に公開します。
公開されるのはアプリ本体（`index.html` / `css` / `js` / `data`）だけです。

最初に一度だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。
公開 URL は `https://<ユーザー名>.github.io/<リポジトリ名>/` です。

### 初期設定

| 項目 | 初期値 |
| --- | --- |
| 発音スタイル | イタリア語風（ラテン語に近い） |
| 声 | Microsoft Diego Online (Natural)。ない場合は自然な声を優先して自動で選ぶ |
| プリセット | 帝国兵（速さ 1.20 / 高さ 0.60） |
| 翻訳したら自動で発声 / 抑揚を強調 / 過去形に「エデ」 | すべてオン |

変更した設定はブラウザに保存されます。

ローカルでサーバーを立てる場合:

```
npm start   # http://localhost:8080
```

### 声の設定

- **発音スタイル**（初期値: イタリア語風）でパンツァー語をドイツ語・イタリア語・スペイン語・英語の綴りに置き換え、その言語の音声で読み上げます。
  欧米の言語らしい発音・アクセント・イントネーション（疑問文の語尾上げなど）になります。
  - 資料（アゼルの綴り）や拡張辞書にラテン語・ギリシャ語の綴りがある語は、その綴りで読みます（例: アマーレ → `amare`）
  - それ以外はカタカナから綴りを作ります（例: ナウス → `naus`、サルヴェ → de `salweh` / it `salve`）
  - 選んだ言語の音声が端末にない場合は、日本語音声のカタカナ読みに切り替えます
- **抑揚を強調**: 文を句（読点ごと、最大3語）に分け、文頭を高く・文末へ下げます。疑問文は文末を上げ、感嘆文は強めに読みます。
- プリセット（帝国兵／巫女／古代機械）で速さと高さを切り替えられます。

## 翻訳のしくみ

資料「日本語_パンツァー語翻訳手順」の方針に沿っています。

> ・文法は英語
> ・まず日本語を英文に訳し、単語をラテン～ギリシャ語に置き換える
> ・ラテン～ギリシャ語をカタカナ読み

1. **形態素解析**: 日本語を [kuromoji.js](https://github.com/takuyaa/kuromoji.js)（CDN から読み込み）で単語に分け、助詞・助動詞から主語・目的語・否定・受け身・条件などを判定します。
   オフラインなどで kuromoji を読み込めないときは、辞書を使った簡易解析に切り替わります。
2. **語順の並べ替え**: 英語の語順（主語 → 述語 → 目的語 → その他）に並べ替えます。
   - 否定「ない」→ `デ`、願望「たい」→ `ペス`、受け身「れる」→ `イェ`、条件「たら・なら」→ `アヌ` を述語の前に置きます
   - 「から」→ `アイオ`、「で」→ `インタス`、「まで」→ `ウスクェ` は前置詞として名詞の前に置きます
   - 「AのB」は資料と同じく `Aル B` にします（例: 亞人の → `コーレル`）
3. **単語の置き換え**: 辞書でパンツァー語のカタカナに置き換えます。
   - 資料の辞書（約690語）に加え、一般会話用の拡張辞書（約750語、`tools/extended_dictionary.tsv`）を使います。
     拡張語は資料と同じ方法（日本語 → 英語 → ラテン語・ギリシャ語 → カタカナ読み）で作りました（例: こんにちは → `サルヴェ` salve、駅 → `スタティオ` statio）。
   - 資料に同じ見出しがある場合は、資料の訳を優先します。
   - **地名・人名などの固有名詞と、辞書にない名詞は外来語扱い**です。訳さずに、外来語風の長音表記（東京 → `トーキョー`、先生 → `センセー`）で読みます。英語入力で辞書にない単語も、そのまま外来語として読みます。
4. **英語入力**: 英語の語順のまま、単語を辞書の英訳（`tools/english_glosses.tsv`）からパンツァー語に置き換えます。

辞書にない語は赤で表示し、元の読みのまま発声します。画面下の「単語を追加する」で、そのブラウザ専用の単語を登録できます。

## ファイル構成

| パス | 内容 |
| --- | --- |
| `index.html`, `css/`, `js/app.js` | 画面と音声合成 |
| `js/translator.js` | 翻訳エンジン（ブラウザ / Node.js 共通） |
| `js/phonetics.js` | カタカナ → 各言語の読み上げ用綴りの変換 |
| `js/i18n.js` | 画面表示の日本語 / English 切り替え |
| `.github/workflows/pages.yml` | GitHub Pages への公開 |
| `data/dictionary.js` | 辞書（`npm run build:dict` で自動生成） |
| `tools/build_dictionary.py` | 辞書の生成スクリプト |
| `tools/source_dictionary.tsv` | 資料から取り出した辞書（約690語、アゼルの綴りつき） |
| `tools/english_glosses.tsv` | 英語入力用の英訳対応表（資料の語） |
| `tools/extended_dictionary.tsv` | 一般会話用の拡張辞書（英訳つき） |
| `tests/` | 翻訳エンジンのテスト |

## 辞書の更新

`tools/` の表（タブ区切り）を編集したら、辞書を作り直してください（Python 3 だけで動きます）。

```
npm run build:dict
```

- 資料の語は `tools/source_dictionary.tsv` に「日本語・パンツァー語・分類・補足・種類・綴り」で書きます。
- 英語の対応は `tools/english_glosses.tsv` に追記します。
- 会話用の語は `tools/extended_dictionary.tsv` に「日本語(異表記は|区切り)・パンツァー語・元の綴り・英語・分類」のタブ区切りで追記します。

## 制限事項

- 語順の並べ替えは文節単位の簡単な規則なので、長い文や複雑な修飾関係では資料の訳と異なることがあります。
- 辞書にない名詞は外来語として読み、それ以外（動詞など）は読みのまま残ります。
- 拡張辞書の語は資料にない独自の造語です。
- 発声はブラウザ・OS に入っている音声に依存します。
